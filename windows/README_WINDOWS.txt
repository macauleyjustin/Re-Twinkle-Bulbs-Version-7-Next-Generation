RE: TWINKLE BULBS — VERSION 7: NEXT GENERATION (WINDOWS x64)
============================================================

QUICK START:
1. Extract this folder anywhere (or run Re-Twinkle-Bulbs-v7.0.0-Windows-x64.exe directly).
2. Double-click Re-Twinkle-Bulbs-v7.0.0-Windows-x64.exe.
3. No external DLLs, Java, Python, or MIDI synthesizer installs are required!
   A festive bulb icon will appear in your Windows notification tray (system tray).
4. Right-click the tray icon for Classic Modes, 16 Holiday Scenes, Modern 60fps
   Effects, Holiday Carols (TwinkleSynth stereo waveOut), History & Credits,
   or click / select "Open Command Center & Settings" to open the full browser
   control interface at http://127.0.0.1:19697/remote (Default PIN: 122570).
